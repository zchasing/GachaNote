# 隐私说明

适用于 GachaNote v0.1。简单来说：**你的数据只在你自己的电脑上，GachaNote 不收集任何东西。**

## 不收集什么

- 没有统计、埋点、崩溃上报或广告 SDK，不记录你的使用情况。
- 没有账号系统，也没有服务器；开发者看不到你的 UID、抽卡记录或任何其他数据。
- 不读取剪贴板、不扫描与游戏无关的文件。

## 保存在你电脑上的数据

都在数据目录（默认 `%APPDATA%\GachaNote\`，可在「设置 → 数据」修改）：

| 内容 | 说明 |
| --- | --- |
| 账号 | 游戏、UID、服务器、你填写的备注名 |
| 抽卡记录 | 时间、卡池、物品名、星级，以及导入时的原始记录（用于以后无损导出） |
| 设置 | 语言、主题、代理地址、边栏游戏、上次打开的账号 |
| 备份 | 数据库的完整副本，最多保留 5 份 |
| 卡池数据包 | 从本仓库下载的公开数据（卡池与 UP 名单），不含个人信息 |
| 日志 | 运行日志，保留 14 天 |

删除数据：在「设置 → 数据」里删除账号会同时删除它的全部记录（删除前会自动备份）；卸载应用后手动删除数据目录即可彻底清除。

## 抽卡链接与凭证

- 抽卡链接里的 authkey 是游戏发给你的临时凭证，约 24 小时失效。GachaNote **只把它保存在内存里**，用于本次拉取，不写入数据库、不写入日志，退出应用即丢弃；界面上显示的也是打码后的地址。
- 日志里的链接参数、token 一律打码，UID 只显示首尾少数几位。
- 鹰角账号 token（明日方舟、终末地）：
  - 用登录窗口时，你是在鹰角官网的页面上登录的，GachaNote **不接触你的账号密码**，只在你登录后读取官网发给浏览器的登录状态，用它查询 token，随即关闭窗口。登录窗口是隐身模式，关掉就不留登录状态。
  - token 默认只在内存里使用；只有你勾选「记住 token」时，才会用 Windows 数据保护（DPAPI）加密后存进数据库，只有你当前的 Windows 用户能解密，换电脑或换用户后需要重新登录。数据库里只有密文。
  - 「设置 → 凭证」列出保存过 token 的账号（不显示内容），可以随时清除；删除账号时它的 token 一并删除。
  - 拉取过程中换到的授权码和角色凭证只在内存里使用，不保存。

## 读取哪些本地文件

只在你点「从游戏拉取」时读取，并且只读不写：

- 原神、崩坏：星穹铁道、绝区零：游戏的日志（用于找到安装目录）和游戏内网页缓存，从中找出抽卡历史链接；
- 鸣潮：游戏目录下的 `Client.log`；
- 你在导入向导里选择的文件。

GachaNote 不修改游戏文件，不读取游戏进程内存，也不注入任何东西。

## 联网

GachaNote 只会连接下面这些地址：

| 什么时候 | 连接谁 | 发送什么 |
| --- | --- | --- |
| 你点「开始拉取」 | 游戏官方的抽卡记录接口（米哈游 `public-operation-*.mihoyo.com` / `*.hoyoverse.com`，库洛 `gmserver-api.aki-game2.com` / `.net`） | 抽卡链接里的参数，与游戏内打开抽卡历史时发送的内容相同 |
| 你在登录窗口里登录鹰角账号 | 鹰角官网 `ak.hypergryph.com`（页面由官网提供）、`web-api.hypergryph.com`（查询 token） | 你在官网页面上输入的内容直接发给官网；GachaNote 只用登录后的状态查询 token |
| 你查询鹰角角色或开始拉取 | 鹰角官方接口：`as.hypergryph.com`、`binding-api-account-prod.hypergryph.com`（授权与角色列表）、`ak.hypergryph.com`（明日方舟寻访记录）、`ef-webview.hypergryph.com`（终末地抽卡记录） | 账号 token 与所选角色的 UID，与在官网查询寻访记录时发送的内容相同 |
| 启动时（可关闭）或你在「设置 → 关于」点「检查更新」 | GitHub Releases（`github.com` 及其下载服务器） | 只是下载公开的版本信息（`latest.json`）；你确认更新时再下载安装包 |
| 启动时（可关闭）或你点「检查更新」 | `raw.githubusercontent.com`，失败时改用 `cdn.jsdelivr.net`（本仓库 `metadata/` 目录） | 只是下载公开文件，不附带任何个人信息 |
| 你打开项目主页、Releases 等链接 | GitHub（在浏览器中打开） | — |

- 卡池数据包的自动检查可以在「设置 → 卡池数据包 → 启动时自动检查」关闭；关闭后完全离线也能正常使用（使用安装包内置的数据包）。
- 设置了网络代理时，以上请求都经过你的代理。
- 软件新版本的自动检查可以在「设置 → 关于 → 启动时检查软件新版本」关闭。下载的安装包会先验证发布签名，验证不通过不会安装。

## 导出与分享

导出的文件（UIGF、GNJ、CSV）包含 UID 与完整的抽卡记录，分享给别人之前请自行确认。v0.3 的分享图会提供隐藏 UID 的选项。
