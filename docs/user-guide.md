# 使用说明

适用于 GachaNote v0.1（Windows 10 / 11，64 位）。

## 安装

1. 到 [Releases](https://github.com/zchasing/GachaNote/releases) 下载最新版本的 `GachaNote_<版本>_x64-setup.exe`。
2. 双击运行安装程序，选择语言后按提示安装。安装在当前用户下（`%LOCALAPPDATA%\GachaNote`），不需要管理员权限。
3. 系统没有 WebView2 运行时的话（Windows 10 少数精简版本），安装程序会自动下载安装，需要联网。

### 「Windows 已保护你的电脑」怎么办

GachaNote 的安装包暂时没有购买代码签名证书，第一次运行时 Windows SmartScreen 可能拦截，显示「Windows 已保护你的电脑」「Microsoft Defender SmartScreen 阻止了无法识别的应用启动」。

这是未签名程序的通用提示，并不代表检测到病毒。确认安装包是从本仓库的 Releases 页面下载的之后：

1. 点提示里的 **更多信息**；
2. 出现「应用：GachaNote_…_x64-setup.exe」和「发布者：未知发布者」后，点 **仍要运行**。

如果不放心，可以先按下一节核对安装包的 SHA-256。

### 核对安装包

每个版本的 Release 页面都会列出安装包的 SHA-256，并附带 `SHA256SUMS.txt`。在下载目录打开 PowerShell，运行：

```powershell
Get-FileHash .\GachaNote_0.1.0_x64-setup.exe -Algorithm SHA256
```

输出的 Hash 与 Release 页面上的值一致，说明文件完整且未被改动。

### 卸载

在「设置 → 应用 → 已安装的应用」里找到 GachaNote 卸载。卸载不会删除你的数据；如需彻底清除，再手动删除数据目录（见 [数据保存在哪里](#数据保存在哪里)）。

## 首次导入

打开应用后，总览页会提示导入记录。点 **导入文件** 或 **从游戏拉取**，也可以点边栏的「导入 / 拉取」（快捷键 Ctrl+I）。导入向导分五步：选择游戏 → 选择方式 → 准备 → 进度 → 报告。

各游戏支持的方式：

| 游戏 | 从游戏拉取 | 导入文件 |
| --- | --- | --- |
| 原神 | ✓ 读取游戏缓存 | UIGF v2 / v3 / v4、CSV（GachaNote） |
| 崩坏：星穹铁道 | ✓ 读取游戏缓存 | UIGF v4、SRGF、CSV（GachaNote） |
| 绝区零 | ✓ 读取游戏缓存 | UIGF v4、CSV（GachaNote） |
| 鸣潮 | ✓ 读取 `Client.log` | GNJ、CSV（GachaNote） |
| 明日方舟 | v0.2 起支持登录鹰角账号拉取 | CSV（arknights-gacha-export）、GNJ、CSV（GachaNote） |
| 明日方舟：终末地 | 同上 | 同上 |

### 从游戏拉取（原神、星铁、绝区零、鸣潮）

抽卡记录链接里带有临时凭证（authkey），游戏打开抽卡历史页面时才会生成，大约 24 小时后失效。

1. 启动游戏，在游戏里打开一次 **抽卡历史记录** 页面（原神「祈愿 → 历史记录」、星铁「跃迁 → 跃迁记录」、绝区零「调频 → 记录」、鸣潮「唤取 → 唤取记录」），翻到第一页即可。
2. 回到 GachaNote，在导入向导里选游戏 → **从游戏拉取**。应用会自动在游戏目录查找最新的抽卡链接，找到后显示脱敏后的地址。
3. 选择拉取范围：**只拉新记录**（默认，只拉上次之后的记录）或 **全部重新拉取**，然后点 **开始拉取**。
4. 拉取会逐个卡池分页进行，并有限速，数千条记录通常需要几十秒。完成后显示报告：新增、重复、失败条数，以及写入前自动生成的备份文件名。

找不到链接时：

- 确认刚刚在游戏里打开过抽卡历史，然后点 **重新查找**；
- 游戏装在非默认位置时，应用可能找不到。可以用其他工具取得抽卡链接，粘贴到「粘贴抽卡链接」输入框；
- 提示「抽卡链接已过期」时，回游戏重新打开一次抽卡历史，再拉取。

以后更新记录：打开账号页，点顶栏的 **更新记录**（Ctrl+R），会直接打开这款游戏的导入向导，步骤同上，默认只拉新记录。

### 导入文件（全部游戏）

1. 在导入向导里选游戏 → **导入文件**，把文件拖进来或点 **选择文件**。包含多款游戏的 UIGF 文件可以在第一步点「直接导入文件，自动识别游戏」。
2. 预览表格列出文件里的每个账号：UID、条数、时间范围，以及是「新账号」还是「已有账号，合并」。勾选要导入的账号后点 **导入选中的 N 个账号**。
3. 完成后查看报告。重复的记录会自动跳过，所以同一个文件导入多次也不会产生重复数据。

文件从哪里来：

- **米哈游三款**：从其他抽卡记录工具（如 HoYo.Gacha、genshin-wish-export）导出 UIGF 文件；
- **明日方舟**：用 arknights-gacha-export 导出的 CSV；
- **换电脑、重装时**：GachaNote 自己导出的 UIGF（米哈游三款）、GNJ（鹰角两款与鸣潮）或 CSV。

导入出错时，报告会写明原因和下一步操作；导入要么全部写入，要么一条都不写，数据库不会出现一半的数据。

## 查看统计

- **总览**：每个账号一张卡片，显示限定池（角色、武器 / 光锥 / 音擎）的当前保底和总抽数，其他卡池在「展开」里。点卡片进入账号页。
- **账号页 · 统计**：上方切换卡池（每个分段旁显示当前保底），下方是三项核心指标——当前保底、平均出 UP 抽数、小保底歪率——以及出金历史与稀有度构成。数字旁标「估算」的，是因为记录本身不能确定是否 UP（例如缺少卡池元数据），按规则推断得出。
- **账号页 · 记录**：按卡池、稀有度、时间筛选，按名称搜索（Ctrl+F）；高星记录显示当次用了多少抽、是否 UP。

账号的切换、重命名、导出、删除都在账号页顶栏：下拉菜单切换同一游戏的其他账号，「更多」菜单里有导出、重命名和删除。

## 导出与备份

- **导出**：账号页「更多 → 导出」，或「设置 → 数据 → 导出全部」。米哈游三款可选 UIGF v4.2，其余游戏导出 GNJ，所有游戏都可导出 CSV。
- **自动备份**：每次导入、拉取、恢复、数据库升级之前都会自动备份，保留最近 5 份。
- **手动备份与恢复**：「设置 → 数据」里可以立即备份，或从备份列表选一份恢复（恢复前会先备份当前数据）。

## 设置

- **通用**：语言（简体中文 / English / 跟随系统）、主题（浅色 / 深色 / 跟随系统，边栏底部的月亮 / 太阳按钮也能切换）、网络代理（留空跟随系统代理，修改后重启生效）。
- **数据**：数据目录、备份与恢复、导出、账号管理。
- **卡池数据包**：当前版本、来源，手动检查更新；可关闭「启动时自动检查」。

### 数据保存在哪里

默认在 `%APPDATA%\GachaNote\`：

| 文件 / 目录 | 内容 |
| --- | --- |
| `gachanote.db` | 全部账号与抽卡记录（SQLite） |
| `backups\` | 自动与手动备份 |
| `metadata\` | 下载的卡池数据包缓存 |
| `logs\` | 运行日志，保留 14 天；不含 authkey、token，UID 已打码 |

「设置 → 数据 → 数据目录」可以把数据搬到其他位置（例如网盘同步目录）：应用会把数据库和备份复制过去，重启后生效，原目录的文件不会删除。

## 常见问题

**统计和游戏里显示的保底不一致？**
先确认记录是最新的（点「更新记录」）。官方接口只能查到最近一段时间的记录（例如鸣潮约 6 个月），更早的记录需要从当时用其他工具导出的文件导入，否则最早几次出金的抽数会偏少。

**歪率或平均出 UP 抽数标了「估算」？**
判断某次出金是否 UP 需要卡池数据包里的 UP 名单。名单缺失（新卡池、鸣潮与鹰角部分卡池）时按常驻名单推断。可以在「设置 → 卡池数据包」检查更新。

**提示「抽卡链接已过期」？**
authkey 大约 24 小时失效。回到游戏重新打开一次抽卡历史，再拉取。

**会不会被封号？**
GachaNote 只读取游戏写在本地的缓存或日志文件，不修改游戏文件、不注入进程；请求的是游戏内抽卡历史页面同样使用的官方接口，并做了限速。

**换电脑怎么迁移？**
在旧电脑上「设置 → 数据 → 导出全部」，或直接复制整个数据目录；新电脑安装后导入文件，或把数据目录复制到 `%APPDATA%\GachaNote\`。

**遇到问题怎么反馈？**
到 [Issues](https://github.com/zchasing/GachaNote/issues) 描述问题，附上 `logs\` 里当天的日志（日志不含凭证，发布前也可以自己检查一遍）。
